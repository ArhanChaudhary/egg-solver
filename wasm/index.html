egg-solver: optimal Rubik's cube solver in WebAssembly

Optimal (fewest moves, half-turn metric) solutions with an H48 pruning table, in your browser. The page starts on its own with every available core and the smallest table (h0), so you can solve right away. Larger tables solve faster: generate one below, or load a table file made by the native gen (h6 = 1.8 GiB is a good size for a browser).
