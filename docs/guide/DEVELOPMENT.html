Miri requires a nightly toolchain with its Miri component. The runner documents its toolchain, log-directory and provenance options. Missing backend tools are reported as unavailable, not as successful validation.

The archived scripts/experiments/pgo-solve.sh is a historical experiment, not part of the release build or Pages deployment. Performance history records its scope and limitations.

Editing documentation

Edit Markdown, run the renderer and documentation checks, then update docs/MANIFEST.sha256 with the integrity tool's explicit --update option. Verify it again before committing. Generated HTML is committed for offline reading and regenerated by the Pages build. Archived raw outputs remain unchanged; new summaries link to them.
