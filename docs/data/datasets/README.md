# Benchmark input datasets

[Benchmark catalog](../../BENCHMARK_CATALOG.md)

These are the cube_solver_test input files used or retained by the comparison harness, including random states, fixed-length move scrambles, known-depth sets, distance-20 sets and chunk files. A suffix such as `from50` identifies the starting offset of a chunk; the report parser aligns cube indices before combining them.

The input text is retained exactly. The harness's [MIT license](LICENSE) is included. Timings and speedups belong to the recorded sample sizes and selected builds; the existence of a dataset file does not imply that every solver was measured on every state in it.
