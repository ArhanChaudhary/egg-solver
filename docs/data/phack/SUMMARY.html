Status: collection complete; mode full. Valid runs: 242/242.

Use counters.csv and runs.json for raw values, running percentages and exact commands. stat/.csv are the original perf output. record/.data retain raw sampled profiles; report/annotate/sample text, symbol files, source commit and the profiling-only patch are included. Event unavailability, insufficient counter scheduling and optional PEBS/LBR failures are retained as diagnostics. No failed or unsupported counter is represented as a measured zero.

Counters use acknowledged enable/disable after table load and warm-up. IPC and MPKI are computed within the same counted event group. Completion-based throughput and average node counts have in-flight boundary effects; they are not exact hardware cycles-per-node denominators. Pages requested are labels for interventions; verify actual THP coverage and NUMA placement in placement/. Westmere lacks the current x86 AVX2/BMI2 backend; this bundle uses the portable scalar backend. Uncore/offcore local response labels retain Intel definitions, including remote-cache hits where named.
