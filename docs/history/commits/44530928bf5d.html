simd, tables, gen, lib: descriptive names and docs

  • simd: A32/A64 -> Aligned32/Aligned64; Tabs/TABS -> HotTables/HOT_TABLES with spelled-out fields (moves, move_orients, inverse_moves, co_low_x3, eslot_complement, ...); the generated constants MOVE_ORIENTS, INVERSE_MOVES, SYM_CUBES, SYM_CUBE_INVERSES, SYM_EDGES, SYM_INVERSES (build.rs); premove_inv -> premove_inverse; private masks ORIENT_BITS, ORIENT_WRAP, USED_BYTES, CORNER_ORIENT_BITS; select(condition, if_true, if_false). The module doc explains the shuffle-based compose.
  • tables: Cocsep {entries, representatives, self_symmetries}; cp_*/cd_* -> packed_*/entry_*, "ttrep" -> "sym_to_rep"; key11 -> full_key; Mem -> Memory (anonymous, map_file); entry_pos/entry_lo_mask -> entry_position/entry_low_bits.
  • gen: Gen -> Generator; the BFS steps expand_forward, expand_backward, finish_level, for_word_chunks; the CAS loops are AtomicU64::try_update.
  • lib: crate overview; nthreads -> thread_count.
