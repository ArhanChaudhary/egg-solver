## Original experiment record

NEGATIVE l6: align-all-functions (not merged)

NEGATIVE (l6, build-level experiment, not share.rs): align every function to 64 bytes

rustflags "-C llvm-args=-align-all-functions=6" (here as a .cargo/config.toml change). Tried to remove the
function-alignment part of the layout noise. It did: two share.rs versions whose rounds() sat at 16 vs 48 mod
64 differed by +1.5% at 1T (solve -c 0 -n 100) normally and by +0.2% when both were built aligned. But the
aligned builds were slower overall: solve -c 0 -n 100 at 1T 48.69 ms/cube aligned vs 46.90 unaligned, ~+4%
(different sessions, 6 rotated runs each). Use lld --shuffle-sections layout averaging instead.
