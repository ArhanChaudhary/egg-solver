## Original experiment record

bench: share[:C] option for the work-sharing mode

A last argument `share[:C]` runs the batch or the stream with
`lanes::share::Pool`, at most C cubes in progress (default threads *
lanes; 1 = one cube at a time with all threads), and prints the pool's
event counters on stderr. Batch mode now also checks that every cube was
reported.

  bench /mnt/huge/h11 random:1000:2026 1000 48 20 share
  bench /mnt/huge/h11 dataset/random_state.txt 50 48 20 share:1

Batch random:1000:2026, 48 threads x 20 lanes: 186.8 -> 795 / 811
solves/s, the same lengths (15:1 16:35 17:270 18:662 19:32); 1 thread,
random:100:2026: 15.97 -> 19.42 solves/s. One cube at a time
(random_state, first 50, `share:1`): 3.6 ms per cube at 48 threads
(main: 0.31 s, one lane), 41 ms at 1 thread (main: 0.23 s).
