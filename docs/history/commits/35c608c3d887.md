## Original experiment record

Merge opt/m4-micro: micro round 4, 7 patches (+7.7%)

Seven micro-optimisations of the lane loop, resolve paths and index path:

- lane-loop: active lanes live in lanes[..nactive] (no per-visit active
  test, pointer iteration); the start time moves into the lane.
- node-roles: the node stores its cubes by role (moved side, other side,
  other side's bound and move mask), so there is no side select per child.
  The select moves to make_node (per push).
- rare-check: one wrapping test for the two rare child kinds (r1 == 0,
  r1 > maxval).
- heur-pair: a single HEUR_PAIR[po<<4|pm] entry replaces two lookups, two
  mins and an add.
- index-pext: pext masks are read from TABS (no 64-bit immediates); a
  7-corner co mask; the eo shifts are fused.
- resolve-face: the pending child's face is stored (no division per
  resolve); no dead phase stores.
- phase-encoding: WaitMoved = 0 and WaitOther = 1, so setting the phase is
  one sete; msplit pext on 64-bit operands.
