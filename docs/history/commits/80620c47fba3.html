solve --fast: fast.sh as a flag (largest table, all threads, warm-up, solve time)

User request: "move fast.sh into a CLI flag". solve --fast [SCRAMBLE]... does what fast.sh (89dca7b) did, in the solver itself:

  • the table: the largest hK found (K from 11 down; /mnt/huge, /data2/tables, /data/tables, ./tables), unless a positional TABLE, --table or CUBEOPT_TABLE names one (with --fast, a first argument that is a move and not a file starts the scramble: solve --fast R U R');
  • all threads (-t overrides) on the one cube: the share mode with -c 1 (through solve_all_pinned, s9's pin; -c and -n conflict with --fast);
  • fast.sh's warm-up cube first in the same process (--warmup SCRAMBLE sets another, "" none; the tests use a short one, fast.sh's takes minutes on h0), then the scramble: the time shown is the scramble's own solve time (from solve's line, to 6 decimals, as fast.sh read it), table load excluded;
  • the scramble: the arguments (joined), or 25 random moves, no face twice in a row and no X Y X on opposite faces, from our Rng seeded from the monotonic clock and the pid (SystemTime would change the code of the worker threads' Instant::now calls: clock id no longer constant-folded);
  • fast.sh's lines (table, threads, scramble, solution, length ... (optimal, verified), time ... ms (... M nodes, ... M nodes/s)); --json: one object.

fast.sh's wait for the bench lock is not taken over (this server's agent infrastructure, not the solver's); --help says not to run it beside other heavy jobs. fast.sh is removed; README shows solve --fast.

Legacy forms: byte-identical stdout (compare-h0.sh vs main on h0); the normal path only gained --table as another way to name the table. Hot code: solve's Worker::rounds instruction-identical at page offset 0x310; the pinned thread closure, share::deeper and rounds are instruction-identical to the measured u1-v2 build (frames 0x1000, 0x190, 0x98); bench and gen binaries byte-identical to u1-v2.

Tests: tests/cli.rs solve_fast on h0 (both table forms, the line shapes, --json, exit 2 for a missing table and a bad scramble); a unit test of the random scramble rules (1000 scrambles).
