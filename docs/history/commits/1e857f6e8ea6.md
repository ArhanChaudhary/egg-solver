## Original experiment record

lanes: small tables in TABS

HEUR_PAIR, ALLOWED_AFTER (as `allowed_after`) and a new `face_keep`
(!(7 << 3f)) move into the TABS static, whose base is already in a
register: no `lea` per use. The face cut in note_value and the pop path
becomes a select between `face_keep[f]` and !0 (instead of building the
mask with a shift, a not and a cmov), the HEUR_PAIR index drops its
masks (bounds are below 16: assert_unchecked), and child_node uses
`k_face` instead of dividing `k_m` by 3 (the rare push path now sets
k_face too).
