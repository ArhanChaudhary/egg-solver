## Original experiment record

Compute job-root bounds once per job, with batched prefetch

Job-root lower bounds (normal and inverse) were looked up synchronously
for every job in every iteration (~43K jobs x 2 lookups in each of the last
iterations, each a DRAM miss). Bounds depend only on the job's cube, so
compute them once when jobs are created, prefetching 64 lookups at a time.

Benchmark (./bench.sh: 1000 random states, 48 threads, h11 base 10):
