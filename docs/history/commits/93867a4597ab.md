Backport explicit futex pointer arguments and isolate SysV test attachments

Miri reached the parking_lot_core0.9.12 Linux wait path under seed15 and
rejected its c-variadic reference argument. Vendor the pinned crate with
upstream-style raw u32/timespec pointer conversions and an explicit
timespec type. Use the same production dependency for native and Miri
builds. Preserve licenses and a local patch note; do not alter the locking
algorithm or disable any Miri check.

Add a contended mutex park/wake test. Isolate all SysV segment tests because
the interrupted-loader test forks, temporarily inheriting another test's
attachments and breaking exact nattch assertions. The original failure
(expected2, observed3) reproduced immediately; twenty complete portable
library runs now pass. Retain failed check.sh logs and print their useful
tail rather than discarding the failing test's detail.
