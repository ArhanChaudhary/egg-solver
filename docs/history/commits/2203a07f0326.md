## Original experiment record

check.sh: a private test log per run

check.sh wrote the test output to a fixed /tmp/cube-test.log and then
grepped it for failures. When agents ran it at the same time in several
worktrees, a run could read another run's log (pipefail prevented false
passes, but spurious failures were possible). Found by the r7 review.
Each run now uses its own mktemp log, removed on exit.

No code change: 48-thread and 1-thread throughput are unaffected (only
the script changes).
