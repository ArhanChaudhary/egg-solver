## Original experiment record

benches: criterion micro-benchmarks of the kernels (feature `bench`)

benches/kernels.rs times apply_move, child_lookup, the h11 key (the
reference index, Cocsep::index; the hot path's Solver::index is
crate-private) and lower_bound (index and an h0 lookup), each over a ring
of 1024 random cubes: `cargo bench --features bench`.

criterion is an optional dependency behind the `bench` feature, not a
dev-dependency: dev-dependencies are built by every `cargo test` and
`clippy --all-targets` (check.sh, on six targets), and criterion pulls in
regex, ciborium, itertools and more. Without default features (no rayon,
no plotters). Never in the default build.
