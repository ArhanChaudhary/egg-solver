## Original experiment record

lanes: descriptive local names

Locals and parameters of every lanes.rs function, by hand per function
(the old names are too short for a global rule): `s` -> `solver`;
`pm`/`po` -> `moved_bound`/`other_bound`; `r`/`r1` -> `remaining_depth`/
`child_remaining`; `a`/`b`/`a2`/`b2` -> `moved`/`other`/`moved_child`/
`other_child`; `idx`/`cd` -> `index`/`corner_bound`; `ji`/`x`/`ck` ->
`job`/`order`/`codes`; `mm_n`/`mm_i` -> `normal_moves`/`inverse_moves`;
`children_lo` -> `children_low` (abce87c's `quantize18`); and so on
(the full table is in s8-rename-map.md, and as a script,
s8-lanes-locals-spec.py with s8-fnrename.py, for porting patches).
The temporary `expect(many_single_char_names)` attributes of phase 1 are
gone.
