Subject: [PATCH] NEGATIVE (x-nx): axis inheritance of the other side's value
 (nxopt's same-axis skipval chain in H48 terms)

nxopt inherits a probe through consecutive moves of one axis (nxopt.w
1710-1711, 1736-1737): the UD probe survives U and D. In H48 only half
turns are in H, but for X on an even face F and Y on the opposite face F+1
(they commute), the other side's child cosets coincide:
  H Y^-1 X b = H X Y^-1 b = H X2 (X^-1 Y^-1 b) = H Y^-1 X^-1 b,
  H Y^-1 X2 b = H X2 Y^-1 b = H Y^-1 b.
So the X' child on F (branching on the node's side) can reuse its X
sibling's face-(F+1) other-side value, and the X2 child's face-(F+1) value
is the node's own. Nothing else is shared: other axes do not commute with
X2, and the moved side's cosets H a m share nothing.

This version (v2) relays the X child's tw[F+1] to the parent at pop (a byte
store at a precomputed offset: axis_twin[F/2], the parent's tw[F+1], or a
dummy). The X' child is seeded from axis_twin in child_node. An X whose tw
is known looks up only its moved side, as X' does. The job root is never a
relay target, so the recorded JobX::tw values stay those of main.

Search identity: nodes and lengths are identical (by construction: the
inherited values are the exact table values of the same cosets).
