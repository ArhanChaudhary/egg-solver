simd, tables, gen, lib: descriptive names and docs

  `move_orients`, `inverse_moves`, `co_low_x3`, `eslot_complement`, ...);
  the generated constants `MOVE_ORIENTS`, `INVERSE_MOVES`, `SYM_CUBES`,
  `SYM_CUBE_INVERSES`, `SYM_EDGES`, `SYM_INVERSES` (build.rs);
