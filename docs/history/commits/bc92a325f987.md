## Original experiment record

lanes: fewer µops in the resolve and advance paths

- tw[face] is written only when the X child passes its other-side lookup
  (po <= r1): otherwise X' is in `skip` and never generated, so the value
  is never read (one store less on the most common path, and in advance's
  and push_advance's corner-prune paths).
- lb = max(lb, v - 1) as a signed byte max (bounds are below 128): no
  saturating subtraction.
- advance computes m % 3 as m - 3 * face (LLVM divided twice).
- resolve_moved tests the child for solved only when its bound is 0 (a
  positive lower bound cannot be the solved cube).
