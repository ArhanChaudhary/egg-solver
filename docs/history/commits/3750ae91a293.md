## Original experiment record

lanes: resolve prologue before the phase dispatch

NEUTRAL (not for merge). On top of m6-6 (r6final). The common start of
both resolve paths (the lookup count, the sp load, the node's r - 1) is
done before the phase dispatch, so that a dispatch mispredict does not
redo it; the code-0 value path then joins a single dispatch.
