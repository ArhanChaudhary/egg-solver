Merge opt/m6-micro: micro round 6, 6 patches (+8.0% 48T, +6.1% 1T)

Six micro-optimisations of the stream kernel and the index path:

  • nofmax: drop Node::fmax. The face cut needs only v > r, because every earlier value on that face was <= r.
  • tabs: heur_pair, allowed_after and a new face_keep table move into TABS. The face cut becomes a select, and the HEUR_PAIR index needs no masks.
  • index: cache the packed-cocsep pointer in Solver. cocsep3 uses tables pre-scaled by 3, a complemented eslot table and a 32-bit pext, and the k shifts become imul/pext with memory operands.
  • skipcount: count skipped X' moves with bzhi(todo, tzcnt(live)); the node-done test checks live == 0.
  • childnode: child_node in moved/other terms, with one select and no branch on the parent's side.
  • resolve: write tw only when X passes; lb as a signed max; m%3 derived from the face; solved test only at bound 0.

The search is unchanged:

  • random:1000:2026 gives 3295521 / 2785769, lengths 15:1 16:35 17:270 18:662 19:32;
  • depth18 gives 3607979 / 3053364, lengths 18:100.

check.sh passes (exit 0). Instructions per node (cachegrind, v3 build): 164.78 -> 148.79 (-9.7%). TAGE mispredicts per node: 0.751 -> 0.737.
