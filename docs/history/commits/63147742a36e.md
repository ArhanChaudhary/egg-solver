## Original experiment record

Per-child final-iteration ordering (neutral: -4..6% nodes, +0.3% throughput)

Each job keeps an 8-bit statistic per root child (18). An iteration runs in
two phases: phase A runs ~2 children per job (~15% of all children),
highest statistic first, interleaved across jobs (a job's other phase-A
children within one octave run with it); phase B runs every remaining
child job by job in canonical order. Coverage: each (job, child) runs
exactly once per iteration (phase A marks done; phase B runs the rest);
targets still rise one at a time, so the first solution is optimal. Roots
are forced to the normal side (any side choice is complete). X' without
its X sibling uses X's other-side value saved in the job (a position-only
lower bound, valid across iterations), or pulls X into the same run.
