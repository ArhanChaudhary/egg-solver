## Original experiment record

NEGATIVE x-h48: permutation parity bit instead of an EO bit (not merged)

Same table size, h1 (k=1 EO bit) vs p0 (h0 x permutation parity), base 8,
generated by x-h48's gendfs (validated: h0 base 7 equals tables/g0
exactly), 100 cubes each, lengths identical:

| set     | h0 (half size) | h1 (EO bit) | p0 (parity bit) |
|---------|----------------|-------------|-----------------|
| depth15 | 7,407,667      | 3,097,130   | 3,505,014 (+13%)|
| depth16 | 87,978,981     | 39,698,719  | 39,825,187 (+0.3%) |

The EO bit is worth at least as much as the parity bit, so h10 x
parity would not beat h11 at the same size. Not pursued. Generator
branch exp-parity and the run log are in negatives/.
