Original experiment record

solve: optimal solver CLI for cube_solver_test-style input

Reads scrambles (one per line, R3 B1 F2 ... or Singmaster) from stdin and solves them with the work-sharing lanes: -t threads, -l lanes, -c concurrency (1: one cube at a time with all threads; 0, the default: the whole input as one batch), -n count. Prints one line per cube

solved

(seconds: from the cube's start to its solution, its latency with -c 1) and a summary

total cubes wall wall/cube nodes/cube ...

Every solution is verified (BAD <index>, exit status 1).

random_state (500 cubes), 48 threads: -c 0 wall 0.645 s, 1.29 ms per cube (bench main: 3.93 s); -c 1 -n 50: 3.71 ms per cube.

For cube_solver_test's runtest.sh: solved lines carry index ($2), nodes ($4) and seconds ($5); the total line wall/cube ($7).
