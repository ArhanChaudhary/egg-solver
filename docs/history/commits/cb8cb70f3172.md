## Original experiment record

Merge opt/m6-micro: micro round 6, 6 patches (+8.0% 48T, +6.1% 1T)

Six micro-optimisations of the stream kernel and the index path:

- nofmax: drop Node::fmax. The face cut needs only v > r, because every
  earlier value on that face was <= r.
- tabs: heur_pair, allowed_after and a new face_keep table move into
  TABS. The face cut becomes a select, and the HEUR_PAIR index needs no
  masks.
- index: cache the packed-cocsep pointer in Solver. cocsep3 uses tables
  pre-scaled by 3, a complemented eslot table and a 32-bit pext, and the
  k shifts become imul/pext with memory operands.
- skipcount: count skipped X' moves with bzhi(todo, tzcnt(live)); the
  node-done test checks live == 0.
- childnode: child_node in moved/other terms, with one select and no
  branch on the parent's side.
- resolve: write tw only when X passes; lb as a signed max; m%3 derived
  from the face; solved test only at bound 0.
