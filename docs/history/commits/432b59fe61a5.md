## Original experiment record

p5: phase buckets as lane bit masks (negative, +6.9% instructions/node, not timed)

Phase buckets kept as lane bit masks (tzcnt/blsr loops) instead of FIFO
pointer arrays. Search identical.

Why: avoid bucket-fifo's pointer-array stores.

Instructions per node (cachegrind, x86-64-v3 build): 181.9 vs main
35c608c 170.2 (+6.9%; register pressure and spills).
48-thread and 1-thread solves/s: not timed.

Conclusion: not timed because it cannot win. It has 6.9% more
instructions, and bucket-fifo's diagnostics show the reorder alone costs
about 4.5% while removing the dispatch gains only about 4%.

Source: scratchpad p5/neg-bucket-bitmask.patch, made against 35c608c;
applies cleanly.
