Baseline H48-style optimal solver

Rust implementation of an H48-style optimal solver (after nissy-core):

  • geometric cubie model; moves and all 48 symmetries derived and tested against a sticker model; AVX2 cube representation (vcube composition)
  • cocsep (3393 classes) + esep + eo coordinate, hk = h11 >> (11-k)
  • 2-bit table, 254 entries + 4-bit line minimum per 64-byte line
  • BFS generator on true coordinates (h0/h11) with forward/backward switching, self-symmetry handling, and derived hk tables (min-collapse) generated in the same pass (h11 + h8 + h7 in ~2 minutes on 48 cores)
  • tables on hugetlbfs with 1GB pages
  • IDA* with inverse/premove tracking, side selection by branching, no-half-turn trick on tight bounds, staged prefetch pipeline
  • tests: brute-force table check, known-depth states, short scrambles vs independent IDA*, symmetric positions
  • bench: solves/sec over random states, 48 threads
