## Original experiment record

NEGATIVE (c7): per-node overhead probes of the per-child bookkeeping (1T (patch file)

All on 78ce33e. "ns" = c7-childsplit's code (select-based exact slot) with the split disabled
(search identical to main, nodes 3449866 on random:20:5), to isolate the bookkeeping's per-node cost.

| probe                                                     | A median | B median | B vs A |
|-----------------------------------------------------------|----------|----------|--------|
| main vs m1cost: heur -> cheur[stack[1].m] (stale slot)    | 20.533   | 20.550   | +0.1%  |
| main vs m1cost2: cheur[select(sp==0, k_m, stack[1].m)]    | 20.500   | 20.450   | -0.25% |
| main vs ns (select slot, boxed run state, cold next_run)  | 20.533   | 20.317   | -1.1%  |
| v1 (ns + next_run inline(always)) vs v3 (ns, slot 0)      | 20.267   | 20.433   | v3 +0.8% |
| v3 (slot 0) vs v7 (store stack[sp+1].m at generation)     | 20.350   | 20.233   | -0.6%  |
| main vs v4 (ns + cheur in a 32-aligned wrapper)           | 20.600   | 20.133   | -2.3%  |
| main vs v5 (ns + cheur inside the boxed run state)        | 20.533   | 20.317   | -1.1%  |
| main vs v6 (ns + setup_run inline(always) in next_run)    | 20.617   | 20.100   | -2.5%  |

Kept in c7-childsplit: the store-based slot (v7), cold out-of-line next_run, setup_run out of line,
cheur in the lane. Also measured: finish_run reading the job's JobX in whole runs (a cache miss per
job: next_run 4.5% of samples, c4v 1T -1.5% vs main) -> fixed by writing whole-run entries blind and
prefetching them for writing; a sequential f32 sum of the 18 statistics (2% of samples) -> tree sum.
