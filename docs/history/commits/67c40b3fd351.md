## Original experiment record

p5: phase-bucketed lane scheduling with FIFO pointer arrays (negative, -6.1%)

Phase-bucketed round robin: each round visits the WaitOther lanes first,
then the WaitMoved lanes, through FIFO pointer arrays, so the visit needs
no phase dispatch. Search identical (verify.sh).

Why: in the TAGE simulation the phase dispatch was the largest
mispredict site (0.363 of 0.972 per node).

48 threads (bench /mnt/huge/h11 stream 20 30 48 <lanes>, capped,
interleaved, solves/s):

| build                         | run 1 | run 2 | run 3 | median |
|-------------------------------|-------|-------|-------|--------|
| main 35c608c, 20 lanes        | 936.0 | 890.3 | 901.8 | 901.8  |
| bucket-fifo, 20 lanes         | 863.7 | 836.4 | 846.9 | 846.9  |
| main 35c608c, 20 lanes (2nd)  | 901.8 | 896.9 | 894.3 | 896.9  |
| bucket-fifo, 28 lanes (2nd)   | 881.5 | 875.2 | 889.6 | 881.5  |

Change: -6.1% at 20 lanes; -1.7% at 28 lanes; at 24 lanes 865.2 vs main
896.0 (1 run, -3.4%).

1 thread (stream 3 12 1 20, 5 runs, solves/s):

| build          | runs                              | median |
|----------------|-----------------------------------|--------|
| main 35c608c   | 19.42 19.42 19.42 19.42 19.58     | 19.42  |
| bucket-fifo    | 18.08 18.50 18.42 18.08 18.00     | 18.08  |

Change: -6.9% (median; the agent summarised it as about -5%).

Per node: TAGE mispredicts 0.972 -> 0.662 (dispatch 0.363 gone, two loop
exits 0.061 + 0.061); instructions (cachegrind, x86-64-v3 build)
170.2 -> 188.7 (+10.9%: pointer arrays, schedule stores, spills).

Conclusion: the mispredicts drop as predicted, but instructions rise 11%
and the lane revisit gap is no longer constant. The gap spreads to 9..38
visits (main: always 20); likely a lane revisited early still waits for
its lookup. The diagnostics (neg/p5-diag-perm-*) split the cost: the
pointer-array loop about -5%, the reorder alone about -4.5%, while
removing the dispatch gains only about +4%.

Source: scratchpad p5/neg-bucket-fifo.patch, made against 35c608c;
applies cleanly. Listed among 9caf0e2's negatives.
Numbers are the agent's own (not re-measured for this record). Not merged; recorded per the rule that every candidate gets a branch.
