B3, base selection (nxopt tunes BASE empirically, nxopt.w 393), XNX_BASE.
Simulated from the base-10 table, random:1000:2026:

| base | rule | nodes/cube | lookups/cube |
|---|---|---|---|

re-basing only moves exact values into code 0, where max(min, cd) replaces
them. x-h48's exact base-11 emulation: +10.2% nodes. Base 10 stays.
