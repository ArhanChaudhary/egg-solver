p5: phase-bucketed lane scheduling with FIFO pointer arrays (negative, -6.1%)

Phase-bucketed round robin: each round visits the WaitOther lanes first, then the WaitMoved lanes, through FIFO pointer arrays, so the visit needs no phase dispatch. Search identical (verify.sh).

Why: in the TAGE simulation the phase dispatch was the largest mispredict site (0.363 of 0.972 per node).

Change: -6.9% (median; the agent summarised it as about -5%).

Per node: TAGE mispredicts 0.972 -> 0.662 (dispatch 0.363 gone, two loop exits 0.061 + 0.061); instructions (cachegrind, x86-64-v3 build) 170.2 -> 188.7 (+10.9%: pointer arrays, schedule stores, spills).

Conclusion: the mispredicts drop as predicted, but instructions rise 11% and the lane revisit gap is no longer constant. The gap spreads to 9..38 visits (main: always 20); likely a lane revisited early still waits for its lookup. The diagnostics (neg/p5-diag-perm-*) split the cost: the pointer-array loop about -5%, the reorder alone about -4.5%, while removing the dispatch gains only about +4%.
