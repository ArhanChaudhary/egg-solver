NEG share: job statistics as atomic_float::AtomicF32 (fetch_add for add_f32)

Replaces stats: Vec<AtomicU32> (f32 bits) and the add_f32 CAS loop with atomic_float's AtomicF32 and its fetch_add. x86-64 has no atomic float add, and AtomicF32::fetch_add is AtomicU32::fetch_update with compare_exchange_weak: the same loop. The asm is identical:

add_f32 (ours)                  AtomicF32::fetch_add
mov eax, dword ptr [rdi]        mov eax, dword ptr [rdi]
vmovd xmm1, eax                 vmovd xmm1, eax
vaddss xmm1, xmm0, xmm1         vaddss xmm1, xmm0, xmm1
vmovd ecx, xmm1                 vmovd ecx, xmm1
lock cmpxchg [rdi], ecx         lock cmpxchg [rdi], ecx
jne <loop>                      jne <loop>

and in the full build every cubeopt/bench/solve function has the same code as 7608a28 (addresses and call targets stripped; d1-x/fndiff.sh). No work is removed, so nothing to gain: rejected without timing (a dependency for an identical loop).
