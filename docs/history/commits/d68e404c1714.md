## Original experiment record

NEGATIVE: lto = "thin" instead of "fat" (-1.0% at 1T)

Toolchain-only change (Cargo.toml). Thin LTO keeps the hot stream closure
much smaller (1940 vs 5168 disassembly lines) but is slower at 1T in all
three paired runs, so 48T was not run.

1T stream (stream 10 60 1 20; the four binaries of a group run
concurrently, one per L3 slot, 3 runs):

| run    | main   | thin   |
|--------|--------|--------|
| 1      | 20.550 | 20.350 |
| 2      | 20.600 | 20.450 |
| 3      | 20.433 | 20.350 |
| median | 20.550 | 20.350 (-1.0%) |

All numbers are on 78ce33e; the build config is unchanged in cb8cb70.

48T: not run (clearly negative at 1T).
