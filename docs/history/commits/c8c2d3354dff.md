## Original experiment record

p5: diagnostic, lanes visited through FIFO pointer arrays in identity order (negative, -5.1% 1T)

Diagnostic, not a candidate. Main's phase dispatch is kept, but the
lanes are visited through bucket-fifo's FIFO pointer arrays in identity
order (main's visit order).

Why: separate bucket-fifo's costs; this measures the pointer-array loop
and the scheduling stores alone.

1 thread (stream 3 12 1 20, 2 runs, solves/s):

| build                    | run 1 | run 2 |
|--------------------------|-------|-------|
| main 35c608c             | 19.42 | 19.58 |
| pointer arrays, identity | 18.42 | 18.42 |

Change: -5.1% (vs 19.42). Instructions per node (cachegrind, x86-64-v3):
170.2 -> 180.2 (+5.9%). 48-thread solves/s: not recorded.

Conclusion: the pointer-array loop alone costs about 5% (about +10 uops
per visit, mostly spills), almost as much as bucketing can gain.

Source: scratchpad p5/neg-diag-perm-identity.patch, made against 35c608c;
applies cleanly.
