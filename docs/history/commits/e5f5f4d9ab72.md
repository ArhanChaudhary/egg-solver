identical, 0 BAD, tests pass), but latency rises: solve -c 1 at 48T on
500 random states +2.4..+3.8% (18-move +2.5%, 19-move +8%); bench

the runs. Variant with per-thread records / build-time groups: worse
(+4.9..+8.4%). Ideas left (in the patch header): build the run list
during T=17's tail, split only at likely-final iterations, lighter
setup for whole-job runs. Patches and the final WIP diff are in
