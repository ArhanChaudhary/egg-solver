NEGATIVE x-h48: base11-h11 (not merged)

From 63fbdf80a5b17f892ec73161f1f3186c960dfacb Mon Sep 17 00:00:00 2001 From: Ubuntu super@claude-cube.usubflgyqkfexnnpr2q2liw1rb.bx.internal.cloudapp.net Date: Wed, 4 Nov 2026 09:28:55 +0000 Subject: [PATCH] neg: base 11 for the h11 table (emulated exactly from the base-10 table)

nissy-core and cube48opt use base 10 for h11 (codes: <=10 with a fallback, 11, 12, >=13). This count-only experiment emulates a base-11 h11 table exactly with our base-10 one (env CUBE_BASE11=1):

  • true 11 (code 1) falls back like code 0 (group minimum, corner depth);
  • code 2 stays 12;
  • code 3 is 13 if one of the 18 neighbors has code 2 (exactly 12), else

    = 14 (a coset outside the subgroup is 1 + its nearest neighbor away).

random:1000:2026, 8 threads of one CCD (count.sh style); lengths identical (15:1 16:35 17:270 18:662 19:32):
