## Original experiment record

lanes: value of the pending lookup without a branch on the code

NEGATIVE. Against 72ade78 (round-6 "ring" commit on
78ce33e; the code it changes is the same in m6-6).

Solver::value_sel selects between the group minimum (code 0) and base +
code instead of branching on the code (taken ~4.5% of visits, nearly
always mispredicted: ~0.040 mispredicts per node in the TAGE trace).
Search identical (verify OK), check.sh OK.

It costs ~7 instructions per visit (the group-minimum load, its mask,
the max with the corner depth, the base add, the select; cachegrind v3
147.52 -> 156.90 per node) and adds the select to the latency of every
value-dependent branch (po > r1, pm > r1, the face cut), which costs more
than the rare mispredict it removes.
