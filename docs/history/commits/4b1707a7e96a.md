## Original experiment record

Complete no-panic integration with shared tables and fallible workers

Adapt shared-memory tests to the fallible memory and checksum APIs. Join
every scoped worker before returning an error, including when more than
one worker fails. Reject unrepresentable benchmark durations without a
panic. Worker-failure regression tests run on unwind-capable targets.

Validation: full check.sh passed (native, scalar, installed cross targets,
WASM/wasmtime, Bun single/threaded modules, NEON under qemu); the no-panic
scanner passed. Deterministic h8 nodes/lookups and stream/share solution
lengths match the measured 229b99f binaries.
