## Original experiment record

lanes: generate a pushed child's first child from registers

When resolve_moved pushes a child, advance() then reloaded the just-written
128-byte node through store forwarding before generating its first child.
A fresh node has no bound (`lb` = 0) and no skipped moves, and its first move
is an X move (move masks are whole faces, less half turns), which looks up
the other side first. push_advance() generates that child directly from the
node value (cubes, `todo`, `r` in registers); the rare kinds (r1 == 0,
r1 > maxval, empty `todo`) and the cocsep-depth prune fall back to an
out-of-line advance (`advance_cold`).
