## Original experiment record

NEGATIVE: -C relocation-model=static (non-PIE executable) (-0.4% at 1T on 78ce33e, +0.1% on cb8cb70)

Toolchain-only change (.cargo/config.toml). A non-PIE binary can address
statics such as `TABS` with absolute disp32 (+index) addressing instead of
a base register, which frees a register in the hot loop; the register
allocation of the stream closure changes substantially (3907 of 5168
disassembly lines differ, 1464 vs 1487 stack references), but it is not
faster.

1T stream on 78ce33e (ab1t.sh, paired concurrent runs):

| run    | main   | static |
|--------|--------|--------|
| 1      | 20.400 | 20.417 |
| 2      | 20.483 | 20.333 |
| 3      | 20.583 | 20.400 |
| median | 20.483 | 20.400 (-0.4%) |

1T stream on cb8cb70 (m6 stack; the group's binaries run concurrently, one
per L3 slot, 3 runs):

| variant | runs                 | median | vs main |
|---------|----------------------|--------|---------|
| main    | 21.667 21.650 21.650 | 21.650 |         |
| static  | 21.633 21.667 21.683 | 21.667 | +0.1%   |

The table above it is on 78ce33e.

48T: not run (no gain at 1T).
