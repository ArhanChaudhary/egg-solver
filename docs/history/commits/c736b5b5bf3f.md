## Original experiment record

Branchless value() (rejected: -4%)

value() picks max(group min, corner depth) or base+code with
select_unpredictable instead of a branch on code == 0.

The branch predicts well, and speculating past it breaks the dependency on
the table load; the cmov version has to wait for the load. Not merged.

Benchmark (measured by the m1 micro-optimisation subagent, bench stream
20 30 48 16 on top of the edge-conj change, median of 3):

| build              | median solves/sec |
|--------------------|-------------------|
| edge-conj          | 604.4             |
| + branchless value | 579.6             |

-4.1% solves/sec.
