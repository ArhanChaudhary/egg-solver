Original experiment record

lanes: Node without align(64): 96 bytes

NEUTRAL/NEGATIVE (not proposed). On top of the ds-lane patch (Lane hot fields first). Data-structure pass, item 2.

Node without repr(align(64)): 96 bytes instead of 128 (the cubes never straddle a line, the scalars share one, the stack shrinks by a quarter; Lane 3648 -> 2816 bytes). Search identical (verify OK), check.sh OK, share mode lengths unchanged (823.9 solves/s, one run).

Node addresses become sp * 96 (lea + shl) instead of sp << 7 on every node access, which eats the footprint gain; the stack's hot part (the top one or two nodes) was L1-resident anyway.
