## Original experiment record

NEGATIVE p10: map-4k-pages (not merged)

NEGATIVE (p10): load regular table files by mmap (page cache, 4 KiB pages)
instead of copying them into anonymous THP memory on Linux.
h7 base 9, bench stream 1T (two runs each; page cache pages, MADV_HUGEPAGE
on the mapping did not give PMD mappings on this ext4):
  24 lanes: map 1.550 / 1.950, copy (THP) 2.017 / 2.017
  40 lanes: map 2.233 / 2.100, copy 2.217 / 2.217
  64 lanes: map 1.967 / 2.000, copy 2.117 / 2.133
Map is slower or noisier (the page cache can also be reclaimed under memory
pressure, then re-read from disk). Kept: copy is the Linux default
(LoadMode::Auto), map stays the default off Linux (macOS has no THP) and for
hugetlbfs and /dev/shm; CUBEOPT_LOAD=map selects it.
