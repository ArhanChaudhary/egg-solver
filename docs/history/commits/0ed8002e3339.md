## Original experiment record

Rename project, CLI, library and WebAssembly assets to egg-solver

Use egg-solver for the package, CLI, repository, build storage and WASM
assets, and egg_solver for the Rust library and ABI names. EGG_SOLVER_*
settings take precedence; CUBEOPT_* remain fallback aliases. Existing
table trailers and SysV key namespaces remain compatible.

The user requested the naming work during the remaining benchmarks.
Those benchmarks still execute immutable commit 229b99f in its separate
checkout. A temporary old-path symlink supports already-loaded scripts
and will be removed after collection. No timing data is relabeled.

Validation: full native/scalar/ARM-NEON/WASI/Bun-WASM check.sh; no-panic
source enforcement; legacy h8 random1000/depth18 search identity; equal
hot instructions, required page offsets and stack frames for bench/solve
against pre-rename 935cb7f. Final h11 validation remains queued.
