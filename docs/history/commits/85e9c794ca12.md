## Original experiment record

index path: fewer µops per lookup index

- Solver caches `cs.packed_ptr()` (as it does the table pointer): one
  dependent load less per index.
- cocsep3: the byte offset 3 * cocsep of the packed entry, from co_lo,
  co_hi and tetrad-rank tables scaled by 3 (no `lea` x3).
- edge_parts_sym: the eslot table is indexed by the complemented E mask,
  which is also the pext mask of msplit (`e ^ 0x0FFF0000`), so `e` is not
  copied; the pext is 32-bit (no zero-extension of the asm output).
- index_sym: the shifts by k are a multiply by `row_mul` = 1 << (k + 9)
  and a pext by `eo_mask` (the top k eo bits), Solver fields that LLVM
  folds as memory operands, instead of two variable shift counts held in
  spill slots. Solver::k is gone.
