## Original experiment record

share: names, docs and pedantic lints

A readability pass over share.rs. Behaviour is unchanged.

- Descriptive names for cryptic fields, constants and locals: `nf` ->
  `feasible`; `ext_off`, `ext_lev` -> `child_offsets`,
  `extension_moves`; `bids`, `hist`, `groups`, `tmp_ptr` ->
  `key_buckets`, `bucket_counts`, `bucket_starts`, `keys_tmp_ptr`;
  `tlog` -> `task_log`; `Rare`/`rare` ->
  `RarelyWritten`/`rarely_written` (`exhausted` -> `claims_ran_out_ns`,
  `it_*` -> `iteration_*`); `direct` -> `stats_from_atomics`; `n0`, `k0`
  -> `nodes_at_start`, `lookups_at_start`; `nactive` -> `active_lanes`;
  `nopen` -> `open_count`; `tids` -> `next_thread_id`; a cube's
  `root_c`, `root_ci` -> `root`, `root_inverse`; `t0`, `t1`, `t2`, `ts`
  -> `build_started`, `extended`, `published`, `sort_stages_ended`;
  `SLane` and its `l` -> `SharedLane` and `lane`; `NONE` -> `NO_SLOT`;
  `count` -> `counts`. The solver, scratch lane, stage, task, bucket,
  key and node parameters and locals of the build, sort, split and
  donation code also get full names.
- Why-comments: the claim word (one `fetch_add` claims a chunk, and the
  count in the same word tells a late claimer that it got nothing), the
  iteration barrier (`outstanding`: the thread that brings it to 0
  builds the next iteration), the mailbox states (one writer of the
  piece slot, ordered by the state), `Inner::feasible`, and the worker's
  fields.
- Clean under `clippy::pedantic`, apart from `inline_always`. The packed
  claim and task words are decoded by `claim_fields` and `task_fields`.
  The casts that remain (radix digits, bucket indices, task counts, and
  ratios in the trace and counters) have function-level `#[expect]`s
  with reasons. Stage numbers and lane slots are `usize`. The trace
  output moved to the cold `trace_iteration` and `trace_build`, which
  replace a 400-column `eprintln!`. `get_disjoint_mut` replaces
  `two_mut`. `Pool::run` and `Pool::counters` accept a poisoned counters
  lock instead of panicking. The rest is `From` conversions,
  `Instant::elapsed`, `sort_unstable` and named imports.
