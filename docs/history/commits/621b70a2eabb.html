lanes: skip count with bzhi; test the live moves directly

The top of advance's loop computes live = todo & !skip, counts the skipped X' moves below the next live move as bzhi(todo, tzcnt(live)) (all of todo if live is 0), and tests live == 0 for the exhausted node, instead of masking with (lowest(live) - 1) and comparing the remainder with todo: fewer µops, and the exhaustion branch (mispredicted ~0.13 per node) depends on one andn instead of a chain of four.
