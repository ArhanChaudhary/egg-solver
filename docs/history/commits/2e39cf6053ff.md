## Original experiment record

bench: pin worker thread i to CPU i (negative, -0.4%)

Pins each bench worker thread to its own CPU with sched_setaffinity
(PIN=0 disables it). The aim was to cut migrations and scheduler noise.

Run with bench /mnt/huge/h11 stream 20 30 48 20, 4 interleaved runs,
solves/s:

| build          | runs                        | median |
|----------------|-----------------------------|--------|
| main 35c608c   | 934.4 942.1 902.8 898.7     | 902.8  |
| pinned threads | 939.6 921.0 899.1 897.7     | 899.1  |

Neutral (-0.4%, within noise). Not merged.
