## Original experiment record

fast.sh: the fastest optimal solve of one random scramble (largest table, all threads on one cube)

Picks the largest hK table (h11 on 1 GiB hugepages here), solves a warm-up cube and then the scramble
with solve -t $(nproc) -c 1, and prints the optimal solution, its length and the cube's own solve
time (table load excluded). Takes the bench lock so it never overlaps a running benchmark.
Example on the 48-core server: a random 25-move scramble solved optimally (18 moves) in 1.52 ms.
