## Original experiment record

NEGATIVE: target-cpu alternatives to native (znver5, znver4, x86-64-v4, -avx512f)

Toolchain-only change (.cargo/config.toml); this patch carries the
x86-64-v4 variant, the others are in the table. On this machine `native`
resolves to znver5 with the same target features: a znver5 build has the
identical hot loop (only RIP-relative offsets differ), so it was not
timed. znver4 tuning, generic x86-64-v4 tuning and AVX-512 off (native
with -C target-feature=-avx512f: no zmm/k-register code) all change the
hot loop's code but none is faster.

1T stream (stream 10 60 1 20; each group's binaries run concurrently, one
per L3 slot, 3 runs; deltas against the same group's main):

| variant              | runs                   | median | vs main |
|----------------------|------------------------|--------|---------|
| main (group B)       | 20.550 20.600 20.433   | 20.550 |         |
| x86-64-v4            | 20.400 20.450 20.300   | 20.400 | -0.7%   |
| main (group G)       | 20.600 20.550 20.567   | 20.567 |         |
| znver4               | 20.433 20.533 20.583   | 20.533 | -0.2%   |
| native -avx512f      | 20.567 20.433 20.567   | 20.567 |  0.0%   |

All numbers are on 78ce33e; the build config is unchanged in cb8cb70.

48T: not run (nothing ahead at 1T).
