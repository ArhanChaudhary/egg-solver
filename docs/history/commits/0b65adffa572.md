## Original experiment record

Share the other-side lookup between the X and X' children of a face

Moving the moved side by X or X' gives the other side the cosets
H X^-1 b and H X b = H X2 X^-1 b = H X^-1 b (X2 is in the subgroup), so
both children have the same other-side table entry and corner depth (the X2
child already inherits the parent's bound for the same reason). Cache the
X child's other-side value per face in the node and reuse it for X',
skipping one lookup per X' child. Exact identity: no change to pruning or
node counts. Found by the heuristic-analysis subagent (verified on 120K
random cases).
