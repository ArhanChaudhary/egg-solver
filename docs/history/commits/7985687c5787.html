NEGATIVE: nightly toolchain (1.101, LLVM 23.1.5) and nightly -Z flags (0.0% / -0.5% at 1T)

Pins nightly-2026-11-03 via rust-toolchain.toml (stable is 1.99.1 with LLVM 23.1.1). Nightly compiles the hot stream closure quite differently (21 KB vs 31 KB; 3930 vs 5168 disassembly lines) but it runs at the same speed. -Z mir-opt-level=4 on top changes 124 lines and does not help either. -Z min-function-alignment=64 was not timed; it is the same as -C llvm-args=-align-all-functions=6 on stable, which is -0.8% (see the llvm-args negative).
