## Original experiment record

Require an unsafe contract for atomic table-memory views; make Miri failures fatal

A safe caller could retain Memory::bytes, obtain Memory::words, mutate an
atomic word, then read the invalidated byte borrow. Miri reproduces the UB.
Make the word view and low-level BFS entry unsafe, document the write and
aliasing requirements, and audit all callers. Add a compile-fail boundary
check and a joined-writer/byte-reader unit test. The former safe reproduction
now fails with E0133.

The Miri runner now propagates prerequisite and every worker failure,
retains raw logs, checks the complete unit-test catalogue and runs 16 shared
search scheduling seeds. Use default provenance with warnings retained for
parking_lot's exposed pointers; strict provenance remains optional. No
borrow, alignment, bounds, validity or race checks are disabled.

Validation: full check.sh CHECK OK across native, portable, ARM/QEMU,
WASI/wasmtime and Bun/WASM; compile-fail reproduction rejected; runner
failure-injection checks passed. Full x86/portable Miri reruns are running
and remain mandatory before main integration/final validation. Hot
instructions, required placement and stack frames match the validated base.
This adds no runtime optimization; final h11 1T/48T comparison remains in
the approved validation schedule.
