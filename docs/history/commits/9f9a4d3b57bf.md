## Original experiment record

Order final-iteration traversal by previous-iteration statistics (jobs)

Split each IDA* iteration with target d > base+3 into canonical move-prefix
jobs of length min(d - (base+3), 4) (as cube48opt does). For every node that
gets both table lookups, accumulate 2^(12-hA) + 2^(12-hB) into the current
job's statistic. Before each iteration, jobs are sorted by statistic times a
face weight (47525 for U/R/F endings, 58206 for D/L/B, compensating for
fewer canonical continuations), children inheriting the parent's statistic
when the prefix grows. In the final iteration the solution is then found
much earlier. Job roots get their own two lookups so that bounds (and the
tight-bound half-turn masks) are available at the job root.
