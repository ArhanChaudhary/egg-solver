annotations: the measured gain of each optimization, inline

User request: "inline comment every optimization followed by how much % faster that code made it". Comments only, in lanes.rs, solver.rs, coord.rs, simd.rs, tables.rs and gen.rs (share.rs got its own from l6, 55e048e). Each says what the code does and why, then the gain as measured when it was added, with its basis and source:

  • 48T / 1T: bench stream medians of the A/B that added it, e.g. "(+2.6% at 48T when added, prefetch-nta.)";
  • nodes, lookups, throughput or batch time where that is what was measured, e.g. "(-36% nodes, +46% at 48T on a batch when added, job-order.)";
  • for a patch of several pieces measured once: "(part of m4-micro's +7.7% at 48T)", plus the piece's own number where the patch measured it;
  • "(not measured separately)" where no number exists (the parts of the first version, the BFS direction switch, ...). The numbers come from the commit messages and merges of the opt/* branches and git notes (mined into /data/agents/s8/annotations-mined.md; neg/* ignored); none is new. The module doc of lanes.rs is reflowed into two paragraphs (what lanes are; the two sides).
