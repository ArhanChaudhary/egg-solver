## Original experiment record

Default to 20 lanes per thread

After the branch-free child setup and the pending-value hoist, more lanes
help again: the throughput plateau is now 20-24 lanes. 20 is chosen (less
lane memory than 24). Search is unchanged (lane count does not affect the
per-cube search).

Benchmark (bench stream 20 30 48 <lanes>, main 45a5a0b, interleaved, 3 runs
each; two sessions):
