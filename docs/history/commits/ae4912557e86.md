## Original experiment record

hot: the pad checks are compile-time assertions in the pad constants

`pad` was a pub const fn with assert!s (callable at run time). The
checks now sit in the STREAM_PAD and SHARE_PAD constants (a build with
another CUBEOPT_*_PAD fails, as before); `pad` is private and returns
an invalid value instead of asserting. The pads are unchanged (16).
