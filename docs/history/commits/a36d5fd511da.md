## Original experiment record

lanes: child node in moved/other terms

child_node built the child's normal/inverse cubes, bounds and move masks
by branching on the parent's side (`normal`) and then make_node selected
them again by the child's side. Both choices are now one select on
`same` (whether the child generates on the parent's moved side): the
NO_HALF masking is side-independent in moved/other terms (po == r1
masks the moved side's half turns, pm == r1 the other side's), and
make_node's choice (fewer moves, ties to the normal cube, r == 1 normal)
is `cm < cx + normal`. One branch (~0.015 mispredicts per node) and
several cmovs less per push. A debug assertion checks the result against
make_node.
