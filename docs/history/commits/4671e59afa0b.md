## Original experiment record

lanes: skip count with bzhi; test the live moves directly

The top of advance's loop computes live = todo & !skip, counts the
skipped X' moves below the next live move as bzhi(todo, tzcnt(live))
(all of `todo` if live is 0), and tests live == 0 for the exhausted
node, instead of masking with (lowest(live) - 1) and comparing the
remainder with todo: fewer µops, and the exhaustion branch (mispredicted
~0.13 per node) depends on one andn instead of a chain of four.

48 threads (ab48.sh: bench /mnt/huge/h11 stream 20 30 48 20 on the
whole machine; 3 runs interleaved over the stack, solves/s; the first
row is the previous patch). 48T noise was +-3% or more during this
round (other agents and a table backup on the machine):
