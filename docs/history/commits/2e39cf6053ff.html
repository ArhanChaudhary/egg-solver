bench: pin worker thread i to CPU i (negative, -0.4%)

Pins each bench worker thread to its own CPU with sched_setaffinity (PIN=0 disables it). The aim was to cut migrations and scheduler noise.

Run with bench /mnt/huge/h11 stream 20 30 48 20, 4 interleaved runs, solves/s:
