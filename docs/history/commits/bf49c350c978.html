NEGATIVE l6: poolrun-inline-never (not merged)

NEGATIVE (l6): share: Pool::run #[inline(never)] (as part of insulating bench's stream loop from share.rs)

On main 2203a07 (share.rs only). Meant to keep a caller's thread closure from inlining the share setup next to the stream loop. In solve (no stream mode) it only moved code: Worker::rounds landed at 48 instead of 16 mod 64, and solve at 1 thread got slower: -c 0 -n 100 46.90 -> 47.58 ms/cube (+1.5%), -c 1 -n 10 35.92 -> 36.36 (+1.2%) (6 runs each, rotated L3 slots; rounds() byte-identical apart from addresses). Built with -C llvm-args=-align-all-functions=6 the same pair differed by +0.2% / +0.7%, so it is placement, not code. 48T: neutral. Not delivered: bench's own per-mode #[inline(never)] functions (595e424) insulate the stream loop without touching solve.
