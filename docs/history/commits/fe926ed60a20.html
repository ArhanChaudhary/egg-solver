laptop: lanes per table size, README "Running on a laptop"

User request: "so i dont need 62gb and can run it on my laptop". With the direct generator (any k) and the portable backends in place, this sets the defaults that depend on the table size, measured, and documents the laptop path.

Lanes per thread (tables::file::untuned_lanes, the default of solve and bench unless bench <table> tune saved a <table>.tune): 40 up to h8, 32 for h9 and h10 (not measured: no RAM for them here), 24 for h11 (as before). Smaller tables gain from more lanes, also on 1 GiB pages (so not a TLB effect).
