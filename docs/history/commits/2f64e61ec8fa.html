NEGATIVE: target-cpu alternatives to native (znver5, znver4, x86-64-v4, -avx512f)

Toolchain-only change (.cargo/config.toml); this patch carries the x86-64-v4 variant, the others are in the table. On this machine native resolves to znver5 with the same target features: a znver5 build has the identical hot loop (only RIP-relative offsets differ), so it was not timed. znver4 tuning, generic x86-64-v4 tuning and AVX-512 off (native with -C target-feature=-avx512f: no zmm/k-register code) all change the hot loop's code but none is faster.

1T stream (stream 10 60 1 20; each group's binaries run concurrently, one per L3 slot, 3 runs; deltas against the same group's main):
