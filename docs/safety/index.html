Correctness, optimality and memory safety

Documentation home · Detailed UB assessment · Mordant findings

There are three different questions to ask about a fast solver:

Correctness, optimality and memory safety
QuestionEvidence in this projectLimit
Does the returned move sequence solve the input?The solve path checks its result; regression tests and benchmark datasets exercise that behaviorPassing sampled inputs does not cover every possible execution
Is the sequence shortest?Iterative-deepening search with lower bounds; independent short-state search, known optimal lengths, cross-mode checks and comparator agreementComplete correctness of all pruning rules and generated bounds is not established by a checksum or by finite tests alone
Is the implementation free of undefined behavior?Code review, concrete defect reproductions and fixes, Miri, native/backend checks, ASan and TSanThese validate tested executions and stated invariants; they are not a universal proof

The NO_UB report explains the fixed API, bounds, memory ownership and publication defects, the provenance-mode qualifications, and the OS/assembly/backend exclusions. It retains earlier failed or incomplete snapshots as history; the summary identifies the audited source and links the full dated assessment.

Mordant produced 14 distinct native and 70 WASI lint diagnostics, with zero compiler errors in the accepted November 7 runs. Those diagnostics were reviewed. A successful lint run is not a claim of zero warnings or a safety proof.

The no-panic policy removes intentional runtime panic calls from shipped first-party code, with the documented test/constant/debug-assert exceptions. That scanner result does not prove absence of every implicit or dependency panic.

For comparing algorithms, see solution lengths in the complete report. For implementation detail, see the source map.

The November 8 throughput study additionally replayed all 15,000 final solutions in both independent cube models. Its raw validation is a result check on those 500 distinct states, not a new Miri run or universal optimality proof.
